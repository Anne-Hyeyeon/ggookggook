# 꾹꾹이 앱 설계

2026-09-27 브레인스토밍에서 정한 내용입니다. 6개월 전 Next.js 웹앱을 버리고 네이티브 앱으로 다시 만듭니다.

## 왜 다시 만드는가

- 이전 버전은 전신 그림 한 장을 확대해서 혈자리를 보여줬습니다.
- 전신 그림에서 손은 너무 작습니다. 확대하면 흐릿해지고 위치를 정확히 찍을 수 없었습니다.
- 디자인에 AI 기본값이 많았습니다. 영어 대문자 라벨, 글래스모피즘, 해시태그 칩, 동작하지 않는 알림 버튼이 있었습니다.
- 기획이 실사용 상황과 맞지 않았습니다.
- 첫 화면이 전신 지도라서 해부학 지식을 가정했습니다.
- 두통 루틴 하나에 혈자리가 7곳이었습니다.
- 타이머 기본값은 20초인데 설명은 2~3분이었습니다.
- 임신 중 금기 안내가 거의 없었습니다.
- 즐겨찾기를 쓰려면 로그인을 해야 했습니다.

## 목표와 범위

- 실제로 앱스토어와 플레이스토어에 출시합니다.
- 핵심 순간은 "지금 불편할 때"입니다.
- 증상을 고르면 혈자리 2~3곳을 순서대로 안내합니다.
- 사용자가 나만의 루틴을 만들 수 있습니다.
- 루틴에는 이름을 붙이고, 혈자리와 순서와 혈자리별 시간(초)을 정합니다.
- 전신 지도는 둘러보기용입니다. 찾아보기 탭에 둡니다.
- 콘텐츠 검수는 WHO 표준 경혈 위치(2008)와 대조하는 수준으로 합니다. 전문가 검수는 하지 않습니다.
- 그래서 효능 표현은 보수적으로 쓰고 면책 고지를 강하게 넣습니다.

## 화면 구성

하단 탭은 오늘, 찾아보기, 내 루틴 세 개입니다.

- 오늘 탭에는 검색창과 증상 목록이 있습니다.
- 최근에 한 루틴이 맨 위에 한 줄로 붙습니다.
- 증상 목록의 각 줄에는 증상 이름, 혈자리 이름, 소요 시간이 나옵니다.
- 찾아보기 탭은 전신 앞면과 뒷면을 보여줍니다.
- 부위를 누르면 전신 그림이 그 부위로 확대되는 애니메이션이 나옵니다.
- 애니메이션 끝에서 따로 그린 부위 그림으로 넘어갑니다.
- 사용자에게는 확대된 것처럼 보이지만 실제로는 고해상도 부위 그림을 보는 것입니다.
- 손처럼 앞뒤가 있는 부위는 부위 그림 안에서 손등과 손바닥을 전환합니다.
- 내 루틴 탭 위쪽에는 즐겨찾는 혈자리가 모여 있습니다.
- 그 아래에 내가 만든 루틴 목록과 새 루틴 만들기 버튼이 있습니다.
- 맨 아래에는 지난 기록이 쌓입니다.

증상 상세 화면은 루틴 미리보기입니다.

- 누를 혈자리를 순서대로 보여줍니다.
- 총 시간과 주의사항을 함께 보여줍니다.
- "이럴 땐 병원에 가세요" 안내를 붙입니다.
- 버튼은 시작과 내 루틴으로 복사 두 개입니다.

가이드 실행 화면은 한 번에 혈자리 하나를 보여줍니다.

- 부위 그림, 혈자리 점, 혈자리 이름, 위치 설명 한 문장, 타이머로 구성합니다.
- 타이머는 큰 숫자와 지금 할 동작("꾹 누르세요")을 보여줍니다.
- 몇 번째 누르기인지와 일시정지 버튼도 있습니다.
- 아래에는 전체 진행 막대와 다음 혈자리가 나옵니다.
- 양쪽에 있는 혈자리는 왼쪽을 먼저 하고 오른쪽을 이어서 합니다.
- 시간이 끝나면 다음 혈자리로 자동으로 넘어갑니다.
- 루틴 중에는 화면이 꺼지지 않습니다.

완료 화면에는 선화 고양이가 나옵니다.

- "지금은 좀 어때요?"라고 묻습니다.
- 선택지는 나아졌어요, 비슷해요, 더 아파요입니다.
- 답은 기록에 남습니다.
- 기록이 쌓이면 어떤 루틴이 나에게 잘 맞는지 알 수 있습니다.

혈자리 상세 화면에는 부위 그림, 위치, 누르는 법, 관련 증상, 주의사항이 들어갑니다.

- 하트 버튼으로 즐겨찾기에 넣습니다.
- 루틴에 추가 버튼으로 내 루틴에 넣습니다.

루틴 편집 화면에서는 네 가지를 합니다.

- 루틴 이름을 짓습니다.
- 검색이나 지도에서 혈자리를 추가합니다.
- 드래그로 순서를 바꿉니다.
- 혈자리별 시간을 10초 단위로 조절합니다. 숫자를 눌러 직접 입력할 수도 있습니다.

첫 실행 화면은 안내 두 장과 면책 동의입니다. 고양이가 여기서 처음 인사합니다.

설정 화면에는 다음이 있습니다.

- 리듬 진동 켜기와 끄기
- 누르기와 쉬기의 기본 초 (기본값 5초와 2초)
- 임신 중 옵션
- 로그인과 기기 간 동기화
- 면책 고지
- 데이터 삭제와 탈퇴

로그인하지 않아도 모든 기능을 쓸 수 있습니다. 로그인은 동기화를 켤 때만 합니다.

용어는 "루틴"을 씁니다. 기본 제공은 "두통 루틴"처럼 부르고, 사용자가 만든 것은 "내 루틴"이라고 부릅니다. "처방"은 의료법과 앱 심사 문제로 쓰지 않습니다.

## 타이머

- 사용자는 혈자리마다 총 시간만 정합니다.
- 그 시간 안에서 앱이 누르기와 쉬기 리듬을 진동으로 알려줍니다.
- 기본 리듬은 5초 누르고 2초 쉬기입니다.
- 리듬 진동은 설정에서 끌 수 있습니다.
- 양쪽 혈자리는 정한 시간을 한쪽마다 적용합니다.
- 예를 들어 합곡 60초는 왼손 60초 다음에 오른손 60초입니다.

## 시각 디자인

- 방향은 "기록지"입니다. 종이 위에 먹으로 쓴 기록 같은 느낌을 냅니다.
- 배경은 아주 밝은 회색 `#F8F8F7`입니다. 노란 기가 도는 크림색은 쓰지 않습니다.
- 본문 글자는 `#23211E`입니다.
- 보조 글자는 `#6A665E`와 `#8A857C`입니다.
- 구분선은 `#E2E2DF`입니다.
- 카드와 시트는 흰색 `#FFFFFF`입니다.
- 강조색은 인주색 `#C23B2A` 하나입니다.
- 인주색은 혈자리 점, 소요 시간, 타이머 숫자, 진행 막대 같은 포인트에 씁니다.
- 일러스트 선 색은 `#3A3732`입니다.
- 글꼴은 Pretendard입니다.
- 명조(Noto Serif KR 700)는 혈자리 이름에만 씁니다.
- 영역은 카드보다 얇은 괘선으로 나눕니다.
- 버튼과 입력창은 모서리를 거의 둥글리지 않습니다.
- 영어 대문자 라벨, 글래스모피즘, 그라데이션, 해시태그 칩은 쓰지 않습니다.

## 일러스트와 캐릭터

- 모든 그림은 가는 먹선 선화입니다. 면 채색과 음영은 없습니다.
- 사람은 한국인 성인입니다. 성별이 드러나지 않고 마른 체형이며 근육 선은 그리지 않습니다.
- 전신 그림은 몸에 붙는 무늬 없는 바디슈트를 입습니다.
- 손, 발, 얼굴, 목은 드러나게 그립니다.
- 손에는 핏줄과 힘줄을 그리지 않습니다.
- 파일은 투명 PNG입니다.
- 전신은 2:3 비율이고 부위 그림은 정사각형입니다.
- 캐릭터는 고양이입니다. 앱 이름 "꾹꾹이"는 고양이가 앞발로 꾹꾹 누르는 행동을 부르는 말입니다.
- 고양이도 같은 먹선 선화로 그립니다.
- 고양이에서 색이 들어가는 곳은 인주색 발바닥뿐입니다.
- 기본 포즈는 사람 어깨 위에서 꾹꾹 눌러주는 모습입니다.
- 고양이는 첫 실행, 루틴 완료, 빈 화면, 로딩, 앱 아이콘에 나옵니다.
- 가이드 실행 화면에는 고양이를 넣지 않습니다. 혈자리를 가리지 않기 위해서입니다.
- 1차 이미지는 `content/images/raw`에 있습니다.
- `body-front.png`는 전신 앞면입니다.
- `hand-dorsal.png`는 손등입니다.
- `cat-shoulder.png`는 고양이입니다.
- 이미지 품질이 부족하면 1차본으로 먼저 출시하고 나중에 교체합니다.

## 콘텐츠 데이터

콘텐츠는 서버에서 내려받습니다. 첫 실행과 오프라인에 대비해 앱 안에도 기본본을 넣습니다.

- 전신 지도는 앞면과 뒷면 그림입니다.
- 전신 지도에는 부위별로 누를 수 있는 영역이 있습니다.
- 각 영역은 하나 이상의 부위 그림으로 연결됩니다.
- 부위 그림은 약 14~16장이 필요합니다.
- 손등, 손바닥과 손목 안쪽, 아래팔 안쪽과 바깥쪽이 들어갑니다.
- 얼굴, 정수리, 뒷목, 어깨와 등 위쪽도 들어갑니다.
- 가슴, 배, 허리, 무릎 뒤도 들어갑니다.
- 정강이 바깥쪽, 종아리 안쪽, 발등, 발바닥도 들어갑니다.

혈자리 한 곳에는 다음 정보가 들어갑니다.

- WHO 코드 (예: LI4)
- 한글, 한자, 영문 이름 (합곡, 合谷, Hegu)
- 양쪽에 있는 혈자리인지
- 위치 설명 한 문장
- 누르는 법
- 기본 시간
- 주의사항 (임신 중 금기 등)
- 참고 문헌 위치
- 그림 위 좌표

좌표는 부위 그림마다 0~1 비율로 저장합니다. 합곡처럼 여러 그림에 나오는 혈자리는 좌표를 여러 개 가집니다.

증상 하나에는 다음 정보가 들어갑니다.

- 이름
- 기본 루틴 (혈자리와 초를 순서대로 2~3개)
- 병원에 가야 하는 경우 안내

콘텐츠 전체에 버전 번호를 붙입니다.

- 앱을 켜면 새 버전이 있는지 확인합니다.
- 새 버전이 있으면 JSON과 이미지를 받아서 저장합니다.
- 그림을 교체할 때는 같은 버전 안에서 이미지와 좌표를 함께 바꿉니다.
- 앱을 업데이트하지 않아도 콘텐츠를 고칠 수 있습니다.

1차 콘텐츠 범위는 다음과 같습니다.

- 기존 증상 16개를 유지합니다.
- 루틴은 증상마다 2~3곳으로 줄입니다.
- 앉은 자리에서 누를 수 있는 손과 얼굴 혈자리를 앞에 둡니다.
- 혈자리는 루틴에 쓰이는 것 위주로 약 30곳입니다.
- 전체를 WHO 표준 경혈 위치와 대조해서 위치와 설명을 고칩니다.
- 기존 데이터는 `content/draft`에 있습니다. 검수 전 초안입니다.

## 사용자 데이터

사용자 데이터는 기기에 먼저 저장합니다. 로그인하면 동기화합니다.

- 내 루틴에는 이름, 혈자리와 초 목록, 순서, 만든 날짜, 수정한 날짜가 들어갑니다.
- 기본 루틴을 복사해서 만든 경우에는 원본 증상도 기록합니다.
- 즐겨찾는 혈자리에는 혈자리 코드와 추가한 날짜가 들어갑니다.
- 기록에는 한 루틴, 시작 시각, 끝난 시각, 걸린 시간, 끝나고 어땠는지가 들어갑니다.
- 설정에는 리듬 진동 여부, 누르기와 쉬기의 기본 초, 임신 중 옵션이 들어갑니다.
- 루틴을 지우면 바로 없애지 않고 삭제 표시만 남깁니다.
- 그래야 다른 기기와 동기화할 때 지운 루틴이 되살아나지 않습니다.

## 앱 구조

- Expo(React Native)로 iOS와 안드로이드를 한 코드로 만듭니다.
- 화면 이동은 Expo Router로 합니다.
- 리듬 진동은 `expo-haptics`로 합니다.
- 루틴 중 화면 켜두기는 `expo-keep-awake`로 합니다.
- 이미지 캐시는 `expo-image`로 합니다.
- 전신에서 부위로 넘어가는 전환은 Reanimated로 만듭니다.
- 기기 저장은 `expo-sqlite`로 합니다. 기록이 계속 쌓이기 때문입니다.
- 화면 상태는 Zustand로 관리합니다.
- 빌드와 스토어 제출은 EAS로 합니다.
- 오프라인에서도 모든 기능이 동작합니다.
- 동기화는 인터넷이 될 때 뒤에서 처리합니다.

동기화 규칙은 단순하게 둡니다.

- 항목마다 수정 시각을 비교합니다.
- 나중에 고친 쪽을 남깁니다.
- 앱은 마지막 동기화 이후 바뀐 것만 주고받습니다.
- 기록은 추가만 되고 수정되지 않습니다. 그래서 충돌이 없습니다.

## AWS 구성

- AWS 연습도 목표에 들어갑니다.
- TypeScript CDK로 인프라를 코드로 관리합니다.
- 리전은 서울(ap-northeast-2)입니다.
- 개발용과 운영용 환경을 따로 만듭니다.

콘텐츠 스택은 콘텐츠 배포를 맡습니다.

- S3 버킷은 비공개입니다.
- CloudFront를 통해서만 접근합니다.
- `manifest.json`은 캐시를 짧게 둡니다.
- 이미지와 JSON은 버전별 경로에 두고 오래 캐시합니다.
- `content:publish` 스크립트가 업로드와 캐시 갱신을 합니다.
- 개인정보처리방침 페이지도 여기서 호스팅합니다.

인증 스택은 로그인을 맡습니다.

- Cognito 사용자 풀을 씁니다.
- 애플, 구글, 카카오 로그인을 연결합니다.
- 소셜 로그인을 넣으므로 애플 로그인은 필수입니다.
- 카카오는 OIDC 공급자로 연결합니다.
- 카카오 설정은 까다로울 수 있습니다. 4단계 초반에 먼저 검증합니다.
- 앱에서는 Cognito 로그인 화면을 PKCE 방식으로 엽니다.

API 스택은 동기화를 맡습니다.

- API Gateway(HTTP API)가 Cognito 토큰을 검증합니다.
- Lambda(Node.js)가 요청을 처리합니다.
- 데이터는 DynamoDB 테이블 하나에 저장합니다. 요금은 사용한 만큼 냅니다.
- `GET /sync`는 바뀐 데이터를 받습니다.
- `POST /sync`는 바뀐 데이터를 보냅니다.
- `DELETE /account`는 탈퇴와 전체 삭제를 합니다.
- 앱 안에서 탈퇴할 수 있어야 애플 심사를 통과합니다.

비용은 AWS Budgets로 관리합니다. 월 5달러를 넘으면 메일이 옵니다.

## 저장소 구조

- `apps/mobile`에는 Expo 앱이 들어갑니다.
- `infra`에는 CDK가 들어갑니다.
- `content`에는 혈자리 JSON, 원본 이미지, 발행 스크립트가 들어갑니다.
- `packages/shared`에는 타입과 동기화 스키마가 들어갑니다.
- 이전 Next.js 코드는 삭제했습니다. git 기록에는 남아 있습니다.

## 이미지 제작 흐름

- 스타일 가이드 문서에 공통 프롬프트를 고정합니다.
- 부위 그림마다 바꾸는 것은 "무엇을 그리는지" 한 줄뿐입니다.
- 이미지는 사용자가 ChatGPT에서 생성합니다.
- 프롬프트마다 새 채팅을 엽니다. 앞 스타일이 섞이지 않게 하기 위해서입니다.
- ChatGPT는 투명 PNG를 검은 바탕에 보여줍니다. 그래서 빛 번짐처럼 보일 수 있습니다.
- 판단은 앱 배경색에 합성한 뒤에 합니다.
- 생성한 이미지는 `content/images/raw`에 넣습니다.
- 스크립트가 여백을 정리하고 캔버스 크기를 맞춥니다.
- 스크립트가 WebP로 바꾸고 해상도별 파일을 만듭니다.
- 좌표 찍기 도구를 따로 만듭니다.
- 도구는 로컬 웹 페이지에서 부위 그림을 띄웁니다.
- 클릭하면 비율 좌표가 JSON에 저장됩니다.
- 옆에 WHO 위치 설명을 띄워서 대조합니다.
- 그림을 교체하면 좌표를 다시 찍고 콘텐츠 버전을 올립니다.

## 안전과 심사

- 첫 실행 때 면책 동의를 받습니다.
- 혈자리 상세 화면 아래에도 짧게 고지합니다.
- 효능은 "도움이 될 수 있어요" 수준으로만 씁니다.
- "치료", "완치" 같은 말은 쓰지 않습니다.
- 스토어 카테고리는 건강 및 피트니스입니다. 의료로 등록하지 않습니다.
- 임신 중 옵션을 켜면 금기 혈자리를 루틴에서 뺍니다.
- 금기 혈자리에는 경고를 보여줍니다.
- 합곡, 삼음교, 견정이 대표적인 임신 중 금기 혈자리입니다. 전체 목록은 1단계에서 문헌으로 확정합니다.
- 증상마다 병원에 가야 하는 경우를 안내합니다.
- 예를 들어 두통은 갑자기 극심해지거나 마비가 함께 오면 병원에 가라고 안내합니다.
- 심사를 위해 앱 안 탈퇴, 애플 로그인, 개인정보처리방침, 추적 없음 표기를 갖춥니다.

## 테스트

- 타이머와 리듬 계산은 단위 테스트로 확인합니다.
- 동기화 병합 규칙도 단위 테스트로 확인합니다.
- 콘텐츠 검증 스크립트를 둡니다.
- 루틴에 들어간 혈자리마다 부위 그림 좌표가 있는지 확인합니다.
- 증상과 혈자리 연결이 서로 맞는지 확인합니다.
- 양쪽 혈자리 표시가 빠지지 않았는지 확인합니다.
- CDK 스택은 구성 검증 테스트를 둡니다.
- 핵심 흐름은 Maestro로 E2E 테스트를 합니다.
- 핵심 흐름은 증상 선택, 루틴 실행, 완료입니다.

## 출시 단계

단계마다 따로 구현 계획을 세웁니다.

1. 콘텐츠 검수와 데이터 구조를 만듭니다. 혈자리 약 30곳을 WHO 기준으로 대조합니다. 루틴을 2~3곳으로 다시 짭니다. 공유 타입도 이때 만듭니다.
2. 오프라인 앱 1차를 만듭니다. 오늘, 찾아보기, 가이드, 완료, 내 루틴, 즐겨찾기, 기록까지 로그인 없이 완성합니다. 이미지는 1차본을 씁니다.
3. AWS 콘텐츠 배포를 붙입니다. 앱 업데이트 없이 콘텐츠를 바꿀 수 있게 합니다.
4. AWS 로그인과 동기화를 붙입니다. Cognito, 동기화 API, 탈퇴 기능을 만듭니다.
5. 스토어 출시를 준비합니다. 앱 아이콘, 스크린샷, 개인정보처리방침을 만듭니다. TestFlight와 내부 테스트를 거쳐 제출합니다.

부위 그림 제작은 1~2단계와 동시에 진행합니다.
